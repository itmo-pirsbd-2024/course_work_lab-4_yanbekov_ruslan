# Разработка сервиса обработки изображений

Цель данной курсовой работы — создание сервиса, который принимает от пользователя набор операций для обработки изображения, выполняет эти операции на сервере и возвращает обработанное изображение. Этот сервис будет включать в себя функциональность для выполнения различных операций

gRPC (gRPC Remote Procedure Calls) — это современный фреймворк для вызова удалённых процедур (RPC), разработанный Google. Он позволяет создавать высокопроизводительные и масштабируемые распределённые системы, обеспечивая эффективное взаимодействие между клиентами и серверами. gRPC использует протокол HTTP/2 для передачи данных, что обеспечивает высокую производительность и низкую задержку благодаря таким функциям, как мультиплексирование потоков, сжатие заголовков и потоковое сжатие данных. 

Для сериализации данных gRPC использует Protocol Buffers (Protobuf), язык описания данных, разработанный Google, который позволяет определять структуру данных в файлах .proto и автоматически генерировать код для сериализации и десериализации этих данных на различных языках программирования.

# Вывод

В результате выполнения данной курсовой работы был разработан сервис обработки изображений, который позволяет пользователям отправлять набор операций для выполнения над изображением и получать обработанное изображение. Сервис поддерживает четыре основные операции: применение черно-белого фильтра, фильтра негатива, изменение размера изображения и поворот изображения на заданный угол. Использование gRPC и Protocol Buffers обеспечило высокую производительность и масштабируемость сервиса, а также упростило взаимодействие между клиентом и сервером.
